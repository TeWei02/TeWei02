## Core Research · Project H.O.L.O.

> "The core of a story is experience, not just text. For centuries we have decoded symbols visually to understand stories — but text itself is only the medium to the story world."

| Aspect | Content |
| :--- | :--- |
| **Problem** | Narrative is only accessible through reading; the reader stays a spectator |
| **Method** | Deep semantic analysis of text → multimodal semantic modeling → rebuilt as auditory & sensory feedback |
| **Model** | Cognitive Rhythm Alignment (CRA): real-time tracking of reading behavior & cognitive state, dynamically adapting content presentation |
| **Implementation** | [ModernReader](https://github.com/TeWei02/ModernReader) — reference implementation of this program |
| **Status** | Proof of Concept (PoC) · Finalist, 2026 Cross-Strait Entrepreneurship Competition |

## Benchmarks

Performance is the easiest thing to write prettily — and to gloss over. I put the numbers I measured myself on one page, including results that don't flatter my own projects.

| Benchmark | What was measured | Result |
| :--- | :--- | :--- |
| [**Look-ahead distance sweep**](https://tewei02.github.io/benchmarks/#ros-chart) | Robot path-tracking benchmark's response to its only parameter (10 look-ahead distances × 6 scenarios) | The originally used `Ld = 30` was not a good operating point: reward **25%** below the measured optimum, tracking deviation **2.3×** |
| [**Pipeline stage costs**](https://tewei02.github.io/benchmarks/#pkt-chart) | Packet-analysis pipeline timing at 200 / 1,000 / 5,000 / 20,000 packets | Loading eats **81%** of the time; everything after parsing totals under **0.07s** |

Every number is measured by the project's own code, written to JSON, and rendered directly from the data file — so the page can't drift from the data. Both benchmarks have built-in guards that verify the sweep didn't run off the rails and exit non-zero otherwise.
