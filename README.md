## 核心研究 · Project H.O.L.O.

> 「故事的核心在於體驗，而非僅是文字。數百年來，我們透過視覺解碼符號來理解故事——但文字本身，僅是通往故事世界的媒介。」

| 面向 | 內容 |
| --- | --- |
| **問題** | 敘事只能透過閱讀取得，讀者始終是旁觀者 |
| **方法** | 深度語意分析解構文本 → 多模態語意建模 → 重建為聽覺與感官回饋 |
| **實作** | [ModernReader](https://github.com/TeWei02/ModernReader) 為此計畫的參考實作，內含 Cognitive Rhythm Alignment (CRA) 模型，即時追蹤閱讀行為與認知狀態並動態調適內容呈現 |
| **狀態** | 概念驗證（PoC）階段 · 2026 海峽兩岸創業大賽決賽入圍 |
